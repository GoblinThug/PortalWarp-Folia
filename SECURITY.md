---

## Reporting a vulnerability

If you find a security issue (permission bypass, crash via plugin commands, unsafe data handling):

1. **Do not** open a public Issue with a full exploit write-up.
2. Contact **Goblin_Thug** privately (DM / Discord / contacts listed in the repository).
3. Include:
   - plugin and server versions (Paper / Folia);
   - reproduction steps;
   - expected vs actual behavior;
   - impact assessment (who can abuse it, whether OP is required, etc.).

The author will try to respond within a reasonable time and ship a patch release if the issue is confirmed.

Thank you for helping keep servers safe.
